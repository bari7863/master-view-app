# DB同期ガイド(Neon ⇔ Supabase / ローカル)

3つのDB(Neon=本番、Supabase=バックアップ、ローカルPostgreSQL=開発用)の内容を揃える・復旧するためのコマンド集。

## Neonの内容でSupabase・ローカルPostgreSQLを揃える

**使うタイミング**: Neonでリストの追加・削除・精査・クローリングを行った後、バックアップを最新化したいとき。

```bash
npm run sync:backup
```

Neonの`master_data`テーブル(スキーマ+データ全件)を、Supabase・ローカルPostgreSQLへ完全に複製する。実行のたびに反映先の既存データは上書きされる。

**重要な注意点**: これは「常に最新のNeonの内容で上書きするミラー」であり、世代管理(過去の一時点への復旧)はできない。誤ってNeon側でデータを壊してしまった直後に気づかず実行すると、唯一のバックアップだったSupabase側の正常データも同時に上書きされ、復旧できなくなる。Neon側で何か想定外の操作(誤削除等)が起きた疑いがある場合は、状況を確認してから実行すること。

## Supabase(バックアップ)の内容でNeonを復旧する

**使うタイミング**: Neon側のリストに問題が起きた場合のみ。

```bash
npm run sync:restore
```

Neon本番への書き込みを伴うため、実行すると確認を求められる。`yes`と入力した場合のみ実行される。
